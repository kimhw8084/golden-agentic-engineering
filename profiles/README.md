# Profiles and capabilities

Profile is a single baseline: `react`, `nicegui`, `python`, or `other`. Capability flags are evidence-backed **declarations** (ui, api, database, jobs, observability, mcp, ai, manufacturing_data). Criticality is `simple`, `workflow`, `production-critical`. Missing capability declarations **do not prove a check is inapplicable**: during qualification, repository structure and design must be reviewed and claimed non-applicability must be validated. Pilot engine trusts declarations but production Golden must verify them independently.
