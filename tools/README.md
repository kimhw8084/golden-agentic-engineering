# Candidate sources — evaluation leads, not a complete capability inventory

The machine-readable `candidates.json` contains **64 candidate public GitHub repos**, grouped into `pilot`, `extended` and `research` tiers. It includes 1 explicitly typed `agent-skill` candidate; most entries are software/tool sources. This is an evolving lead list, not a complete inventory of relevant agents, skills, MCP servers, or requirements-matched GitHub projects. `license_hint_unverified` is only a search lead, not a legal statement or qualified source version. All new imports must pass company OSS/IP clearance, including dependencies/assets and commercial-use constraints.

**Select by task evidence, not by tool category.** Pilot tier is for evaluation, not simultaneous installation. Begin by discovering approved OpenCode agents, relevant skills, and connected MCP capabilities; exercise the best-fit agentic workflow. Compare CLI candidates against that workflow for the same task, and prefer a CLI for a specific operation only when it performs better on the stated acceptance criteria. A hybrid may be best: agent/skill for reasoning, MCP for structured service access, CLI for deterministic local operations and checks.

`tools/candidates.json` lists public source repositories for possible tools and skills. It is not a complete inventory of agentic capabilities and it is not a ranked list. Do not use it as a substitute for inspecting the capabilities of the actual company OpenCode installation.

The `pilot` diagram skill [`cathrynlavery/diagram-design`](https://github.com/cathrynlavery/diagram-design) is an unqualified evaluation lead. Its upstream README documents copying or symlinking `skills/diagram-design/` into OpenCode's skill directory; there is no OpenCode marketplace package or automatic update path. Evaluate it for polished, occasionally published diagrams. Keep Mermaid/D2 for frequently edited diagrams where source diffs matter. Set the skill to system fonts for offline/no-network rendering. The upstream license hint and all dependencies/assets remain subject to company review.

`python scripts/fetch_sources.py --tier pilot` previews URLs. The downloader with `--apply` is for approved public internet staging computers only; it clones sources and hashes them. Source snapshots alone are **not** an offline executable bundle.
