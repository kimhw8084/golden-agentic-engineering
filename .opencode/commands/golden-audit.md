---
description: Inspect a codebase and run evidence-based Golden checks
---
Audit $ARGUMENTS using the pinned Golden release. Run fast or full deterministic checks as appropriate; account for every rule, including NOT_APPLICABLE with basis, NOT_RUN and DEFERRED. For genuine defects explain root cause and a concrete fix. Never modify code as part of this audit unless separately asked by the application owner. This command is an investigation, not release approval.
