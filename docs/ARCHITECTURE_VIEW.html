02 / Where real applications live

Existing team application platform

Hosts real apps, user feedback collection and a single React observability view. Prometheus, Grafana and Splunk remain the monitoring systems of record.

Golden Control (optional later)

Lightweight browser for standards, approved tools, versions, policies and customization. No app registry, production hosting, or application compliance dashboard.

03 / Daily agentic task routing

Agentic-first default

Primary agent + route skill

Clear small fixes stay direct. For nontrivial work, invoke the matching skill, check only relevant live agents/MCP and permissions, then choose implementation tools. Compare CLI per operation only when it is a plausible alternative.

Complex / purposeful

Bounded delegation

Architecture or independent review when expected benefit justifies the coordination cost. Avoid unbounded swarms or overlapping edits.

Qualification

Independent real tests

Deterministic outcomes, targeted repair and retest. Do not confuse AI explanation with executed proof or self-reported calls with trusted traces.
